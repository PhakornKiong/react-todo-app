Goal

Perform a safe, incremental remediation of supply-chain vulnerabilities reported by `npm audit` by (1) applying non-breaking fixes, (2) upgrading dev dependencies—focusing on `react-scripts`—and (3) verifying the repository builds and tests cleanly in CI and a canary/staging preview. Scope

In scope

- Generate and commit a deterministic lockfile (package-lock.json) and any safe non-breaking fixes (npm audit fix).

- Create PR(s) with clear migration notes, audit report, and test results.

Out of scope
- Major application refactors (UI or runtime behavior) unless strictly required by an unavoidable dependency upgrade.
- Upgrading production runtime libraries (react/react-dom) unless a security fix forces it; if required, handle in a separate change with its own plan.
